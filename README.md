# LingoLeaf · 轻译 1.4 — 安装即用的网页与文本翻译

Edge 网页与文本翻译扩展。安装后可直接使用公共免费额度，无需注册或填写 DeepSeek API Key；也可随时切换为自己的 DeepSeek Key。支持翻译网页正文、替换网页外文、输入独立文本，以及流式解释选词。**使用扩展无需 Node.js、本机服务或配对码。**

[隐私说明](PRIVACY.md) · [安全政策](SECURITY.md) · [MIT License](LICENSE)

## 安装与升级

1. 解压 `LingoLeaf-Edge-v1.4.zip`。
2. 在 Edge 地址栏输入 `edge://extensions`，开启「开发人员模式」。
3. 点击「加载解压缩的扩展」，选择解压后的 **`LingoLeaf/extension` 文件夹**，其中包含 `manifest.json`。
4. 固定工具栏中的「LingoLeaf · 轻译」。首次使用会自动建立匿名会话，无需填写密钥。
5. 回到普通网页，刷新页面，在扩展中选语言并点击「开始翻译此页」。
6. 如需使用自己的额度，在设置中切换到「我的 DeepSeek API Key」并导入密钥。

**从 1.3 升级：**用新版 `extension` 内容覆盖原加载目录，在 `edge://extensions` 中重新加载轻译，再刷新需要翻译的网页。已有个人 Key 的用户继续使用个人模式；新安装默认使用免费服务。1.4 增加对项目专属 Supabase 域名的访问权限，用于匿名认证、额度检查和服务端翻译代理。

从 1.0 升级时，需导入 DeepSeek 密钥并允许 DeepSeek API 访问。旧版 OpenAI 模型和配对码不会当成 DeepSeek 密钥，原本机服务可关闭。

## 新增：只翻译正文

1. 打开文章网页，点击轻译工具栏图标。
2. 在「翻译范围」中选择 **「仅正文」**，再选目标语言。
3. 点击 **「识别并翻译正文」**。识别成功后，正文仍按原文与译文逐段对照，随滚动继续翻译。

已在翻译时切换范围，会清理旧范围的译文并开始翻译新范围；暂停时切换则等待再次点击开始。所选范围会保存，后续手动翻译、已授权网站的自动翻译及快捷键均沿用该设置。按暂停或还原可随时停止。

正文识别**完全在本地完成**，结合 `article`、`main`、文章容器、段落长度、标点、文本密度、链接密度和多篇文章结构判断，不额外调用 DeepSeek。通常包含文章标题、小标题、段落、列表及表格；过滤能从网页结构识别出的导航、侧栏、页脚、评论、推荐和广告模块。正文异步加载或 SPA 切换文章时重新识别。

识别不确定时显示「未识别到明确正文，可切换整页翻译」，不会自动扩大到整页，也不会为识别调用 API。首页、搜索结果、文章列表、极短内容、缺少结构的特殊网页可能无法识别；此时切换「整页」即可。识别是启发式判断，无法保证所有网站都准确。隐藏或未加载的内容不会被提取。识别最多检查前 2 万个非空文本节点，以限制超大页面开销。

## 网页显示方式

网页翻译固定使用简洁结果，不生成注释和例句，并可选择两种显示方式：

- **对照：**保留原文，将字号略小的译文直接显示在对应文本右侧；不使用浅绿色文本框，空间不足时自动换行。
- **替换：**显示所选目标语言的译文，并暂时隐藏对应原文。鼠标悬停译文可查看原文，键盘聚焦时也有完整辅助说明；点击「还原」会恢复原始文本节点、链接和行内结构。

切换目标语言、翻译范围或显示方式时，扩展会先还原旧结果，再按新设置翻译。暂停不会破坏页面，随时可以继续或一键还原。

## 文本翻译

在插件顶部切换到「文本翻译」，输入最多 6000 个字符，选择目标语言和输出模式：

- **纯译文：**只输出译文内容。
- **译文＋简注：**输出完整译文，并补充少量用词或语气说明，不生成例句。
- **深度讲解：**输出译文、含义与语气、重点词语或语法，以及双语例句。

结果会流式显示，可随时停止、复制或清空；输入区显示实时字数。扩展不保存输入历史，关闭页面会取消仍在进行的请求。

## 免配置免费服务

新安装默认通过项目专属 Supabase Edge Function 调用 DeepSeek。扩展自动创建不含邮箱、手机号或姓名的匿名会话；每位匿名用户每天最多翻译 2 万字符，公共服务每天最多 20 万字符。额度用完后可次日继续，或切换为自己的 DeepSeek Key。

DeepSeek Key 只保存在 Supabase Edge Function Secrets，不会进入扩展安装包、浏览器存储或 GitHub 仓库。服务端重新校验语言、文本长度和输出模式，并固定 DeepSeek 请求地址与 Prompt；客户端不能指定任意上游地址或绕过额度函数。

匿名身份保存在扩展本地存储，用于刷新会话和计算每日额度。卸载扩展会失去该匿名身份。免费服务属于有限公共资源，额度和可用性可能随运营成本调整。

## 使用个人密钥

从 [DeepSeek 开放平台](https://platform.deepseek.com/api_keys) 获取自己的 API Key。

支持直接粘贴，或导入最大 16 KB 的文件：

- `.txt`：内容只有密钥，允许首尾空白。
- `.json`：对象字段支持 `apiKey`、`api_key`、`DEEPSEEK_API_KEY`、`key`；也支持 JSON 字符串。

JSON 示例（将示意文字替换为完整密钥）：

```json
{"apiKey": "你的完整 DeepSeek API Key"}
```

文件仅在设置页本地解析，不上传文件。导入后点击「保存并验证密钥」生效。

个人密钥默认存在扩展会话存储，关闭浏览器后需重新导入。勾选「在此浏览器记住密钥」后存入扩展本地存储，不参与账号同步。本地存储不是加密保险箱，能访问本机浏览器配置文件的人仍可能读取它。「清除密钥」移除会话和本地副本，切回免费服务，并取消未完成的网页请求。

## 功能

- 中文、英语、法语、俄语、西班牙语、阿拉伯语六种目标语言，自动识别原文语言。
- 默认免费服务无需 API Key；可选个人 DeepSeek Key 作为备用或解除公共额度限制。
- 整页 / 仅正文两种范围，本地智能识别正文，动态重检，不增加 API 识别费用。
- 网页固定简洁翻译，支持紧凑的原文/译文对照或直接替换；阿拉伯语 RTL。
- 独立文本翻译支持纯译文、译文加简注、深度讲解三种输出，以及流式显示、复制、清空和字数统计。
- 优先翻译视口上下 350px 内的段落，支持滚动、动态加载、文字更新、隐藏内容展开。
- 选词右键「轻译 · 智能解释」：**DeepSeek** 根据上下文流式解释含义、语法、用法及双语例句，解释语言可独立设置。
- 保留附加「在 ChatGPT 中解释」网页入口：复制问题，打开 ChatGPT 后手动粘贴发送。该附加入口不使用 DeepSeek 密钥，也不参与自动翻译。
- 按网站授权并记忆自动翻译，暂停、继续、一键还原；快捷键 `Alt+Shift+L`。
- 原生 JavaScript/CSS，零第三方运行依赖，无遥测、广告、远程脚本；动效尊重系统「减少动态效果」。

## 模型与连接

免费服务的模型由服务端统一配置，当前默认 **`deepseek-v4-flash`**，使用官方 `https://api.deepseek.com/chat/completions` 和 `thinking: {"type":"disabled"}` 非思考模式。个人 Key 模式可选 `deepseek-v4-pro`，或填写账户支持的 DeepSeek 模型 ID。

网页翻译使用 JSON Output，扩展再次校验段落数量、编号及完整性。文本翻译与选词解释使用 SSE 流式输出，只显示最终回答内容，不显示推理内容。

个人模式的密钥验证请求 `/models`，检查凭据和模型列表，不生成翻译。「测试一句翻译」会实际调用当前所选服务并消耗少量额度。弹窗「免费服务可用」表示客户端配置完整，实际可用性仍受当天额度和模型服务状态影响。

| 提示 | 处理方式 |
| --- | --- |
| 401 密钥无效 | 重新导入完整 DeepSeek Key |
| 402 余额不足 | 在开放平台检查 API 余额 |
| 404/422 模型或参数错误 | 检查模型 ID 和账户权限 |
| 429 请求限流 | 稍后点击继续或重试 |
| 503 服务繁忙 | 稍后重试 |
| 超时/无法连接 | 检查网络与扩展 API 权限，或缩短文本 |

实际速度取决于服务、模型与文本长度，不保证固定毫秒延迟。网页翻译与解释默认 28 秒请求超时，文本翻译为 45 秒；网页出现错误时暂停，避免持续重试消耗额度。

## 性能、隐私与兼容范围

- 每批最多 6 块、6000 字符；长段落按约 1100 字符分块，完整返回后显示。
- 文本翻译每次最多 6000 字符；点击停止、关闭文本页或离开插件会中止未完成请求。
- 网页翻译最多 2 个并发请求，同批去重，后台最多缓存 400 条结果，按模型与语言隔离。
- 每轮最多发送 6 万字符，达到后暂停，点击继续开启下一轮；最多追踪 2000 个段落。
- 合并动态检测、空闲分片扫描。暂停、还原、离开页面会取消网页请求，迟到结果不再插入。已发送的请求可能已经计费。
- 免费服务通过 HTTPS 将待译文本发送至项目专属 Supabase Edge Function，再由函数调用 DeepSeek；个人模式则由受信任扩展后台直接调用 DeepSeek。内容脚本无法读取个人密钥或云端会话令牌。
- 网页和文本翻译仅在用户开始翻译时发送待译内容；解释最多发送 3000 字符选词和 1800 字符上下文至 DeepSeek。默认跳过编辑框、代码、按钮、隐藏内容、`translate="no"` 和 `.notranslate` 内容。
- 不保存网页历史，缓存仅在后台内存，工作进程重启后清除。DeepSeek API 自身数据处理与计费遵循其政策和你的账户设置。
- 支持桌面 Edge 普通 HTTP/HTTPS 顶层网页。浏览器内部页、扩展商店、内置 PDF、图片、Canvas、闭合 Shadow DOM 不在自动翻译范围内。跨域 iframe 不自动扫描，可尝试选词右键解释。
- 本地开发版，尚未上传扩展商店，也没有自动安装到日常浏览器。

## 开发与验证

用户安装运行无需 Node.js。开发者运行测试需 Node.js 22+：

```text
node --test tests/*.test.mjs
```

可复现浏览器检查：运行 `node tests/browser-server.mjs`，用 Edge 打开 `http://127.0.0.1:19403/article.html` 并点击「运行正文测试」。整页回归页为 `/fixture.html`，点击「运行网页测试」。保持测试页在前台；这些页面直接加载扩展源文件，使用模拟 API，不需要密钥。按 `Ctrl+C` 关闭本地测试服务；该服务仅供开发验证，日常使用扩展无需启动。

本版 27 项 Node 自动测试通过，覆盖匿名注册、令牌刷新、云端配额错误、六语请求、JSON 编号/截断、固定 HTTPS 端点、401/402/429/503、个人密钥验证、SSE 分片、文本翻译三种模式、解释与文本端口、密钥文件导入、会话/本地存储、配置迁移、缓存和取消。

本版在浏览器中通过 24 项正文与替换 DOM 检查，覆盖语义文章、中文、无语义标签页面、短新闻、列表/首页拒绝、外围模块过滤、动态更新、异步加载、SPA 路由、切换范围、暂停继续、自动翻译、快捷键、原文悬停、原文本节点恢复与迟到响应。原有整页功能的 14 项浏览器回归检查也通过，包括长段落分块、隐藏内容、视口延迟、阿拉伯语 RTL 和 API 错误暂停。另人工检查文本翻译三种输出、流式显示、复制、清空、弹窗切换及 380×600 尺寸。开发验证使用模拟响应；**未使用你的真实密钥，账户联调请安装后点击「测试一句翻译」。**

## 自行部署后端

仓库包含可复现的 Supabase 配置。创建项目后执行数据库迁移、开启匿名登录并部署 `lingoleaf-translate`，然后在 Edge Function Secrets 中设置 `DEEPSEEK_API_KEY`。`SUPABASE_PUBLISHABLE_KEY` 可以出现在客户端；Supabase secret/service-role key 与 DeepSeek Key 都不得提交到仓库。
