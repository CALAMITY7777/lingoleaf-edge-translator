01 选择翻译服务

默认免费服务会自动建立匿名会话，无需注册或填写 API Key。每日额度用完后，也可以切换为自己的 DeepSeek Key。

每位用户每天最多 2 万字符；公共服务每天设有总量保护。
1在 DeepSeek 开放平台创建 API Key。
2在下方粘贴，或导入 .txt / .json 文件。
3保存并验证后，翻译请求将直接发送到 DeepSeek。
文件仅在本机读取，不会上传。默认只保留到浏览器关闭。勾选后存入扩展本地存储，不参与账号同步；本地存储不是加密保险箱。
仅用于个人 Key 模式；免费服务的模型由服务端统一配置。

免费服务使用匿名会话和每日额度；测试翻译会消耗少量免费额度。

02 自动翻译的网站

在扩展弹窗中为当前网站开启。只有授权的网站才会自动读取并翻译可见文字。

03 简单，也有边界

密钥留在服务端

免费服务的 DeepSeek Key 只保存在 Supabase Edge Function Secrets 中，不会打包进扩展或公开仓库。

只发送待译内容

翻译文本经 Supabase 代理发送到 DeepSeek；缓存只存在扩展内存，不保存网页和输入历史。
